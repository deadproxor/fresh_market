# FreshMarket — Бэклог задач и планов (Backlog)

Реестр запланированных возможностей, архитектурных улучшений и бизнес-задач экосистемы FreshMarket, разбитый по приоритетам и спринтам.

---

## 🎯 Спринт 1: Платежи и оповещения (Высокий приоритет)

### 1.1. Интеграция платежей KHQR (Bakong)
* [ ] **Генерация динамического KHQR на витрине:**
  * Формирование официального платежного QR-кода стандарта Bakong KHQR на экране оформления заказа.
  * Поддержка оплаты в двух валютах: KHR (камбоджийский риель) и USD по фиксированному курсу закупки.
  * Валидация CRC16 контрольной суммы строки платежного кода.
* [ ] **Интерфейс оплаты (`shop.html`):**
  * Отображение QR-кода в модалке заказа с кнопкой «Открыть в приложении банка» (Deep Link / Bakong app scheme).
  * Инструкция для покупателя по сканированию и подтверждению оплаты.

### 1.2. Telegram Bot Webhook для закупщика
* [ ] **Edge Function `telegram-notify`:**
  * Supabase Database Webhook: автоматический триггер при успешной вставке новой записи в таблицу `public.orders`.
  * Форматированное сообщение закупщику в Telegram: номер заказа, список товаров с граммовками/фасовками, комментариями покупателя, точный адрес доставки, точка на карте и итоговая сумма.
* [ ] **Быстрые действия (Inline Buttons):**
  * Интерактивные кнопки «Взят в закупку», «Собран», «Передан курьеру» прямо в сообщении Telegram для мгновенной смены статуса заказа закупщиком на ходу.

---

## 📊 Спринт 2: Учет цен и аналитика (Средний приоритет)

### 2.1. Аналитика утреннего рынка и динамика цен
* [ ] **Хранение истории цен продуктов:**
  * Таблица `public.product_price_history` для фиксации ежедневных колебаний цен на утреннем рынке.
  * Графики динамики цен в админке закупщика (сезонные скачки, минимальная / максимальная зафиксированная цена за период).
* [ ] **Калькулятор маржинальности:**
  * Автоматический расчет маржи между оптовой ценой утреннего закупа и стоимостью позиции для розничного покупателя.

### 2.2. Экспорт отчетов
* [ ] **Экспорт заказов и закупочного листа:**
  * Экспорт выбранных заказов на день в CSV/Excel для закупщика и курьеров.
  * Печатная компактная форма чек-листа для утреннего обхода рынка.

## ⚡ Спринт 3: Оптимизация платформы и UX (Плановый)

### 3.1. Устойчивость при нестабильной связи (Offline Market Resilience)
* [ ] **Фоновая очередь синхронизации (Background Sync):**
  * Очередь локальных операций в IndexedDB, если закупщик находится в зоне рынка с плохим приемом сотовой сети.
  * Автоматическая отправка накопленных изменений цен и товаров при восстановлении стабильного 4G/Wi-Fi соединения.

### 3.2. Дополнительные языки и локализация
* [ ] **Расширение мультиязычной базы:**
  * Пополнение словаря кхмерских наименований редких местных морепродуктов и зелени.
  * Аудио-произношение кхмерских названий продуктов для иностранных покупателей.
